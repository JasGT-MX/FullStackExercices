Operaciones con SQLAlchemy
En esta lección, realizamos todas nuestras operaciones CRUD con SQLAlchemy en una base de datos SQLite. Antes de realizar cualquier operación, primero debemos importar las bibliotecas necesarias, conectarnos a nuestro archivo restaurantMenu.db y crear una sesión para interactuar con la base de datos:

from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker
from database_setup import Base, Restaurant, MenuItem

engine = create_engine('sqlite:///restaurantMenu.db')
Base.metadata.bind=engine
DBSession = sessionmaker(bind = engine)
session = DBSession()
